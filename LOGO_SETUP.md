# How to Add Your Logo

## Quick Steps

1. **Prepare your logo**:
   - File name: `logo.png`
   - Recommended size: 200x200px to 400x400px
   - Format: PNG (with transparent background preferred)
   - The logo will be displayed at 40px height (width auto-scales)

2. **Add to project**:
   ```
   Place file in: pc-repair-frontend/public/logo.png
   ```

3. **Restart frontend** (if running):
   ```powershell
   cd pc-repair-frontend
   npm run dev
   ```

## Where the logo appears:
- ✅ Navbar (top left)
- ✅ Home page hero section
- ✅ Footer

## If you don't have a logo yet:
You can create a temporary placeholder or use a logo generator:
- Canva: https://www.canva.com/create/logos/
- LogoMakr: https://logomakr.com/
- Hatchful: https://hatchful.shopify.com/
